# ML Ops Toolkit

A lightweight collection of scripts and tools designed to streamline Machine Learning Operations (MLOps). This repository helps automate data pipeline workflows, manage model tracking, and simplify deployment steps.

## Key Features

* **Data Pipelines**: Quick data cleaning and preprocessing utilities.
* **Experiment Tracking**: Simple logging for model parameters and metrics.
* **Easy Setup**: Minimal dependencies for fast deployment.

##  Installation

```bash
git clone [https://github.com/allalyhabiby/ml-ops-toolkit.git](https://github.com/allalyhabiby/ml-ops-toolkit.git)
cd ml-ops-toolkit
pip install -r requirements.txt
